# mojo-neuron v2: causal tools, features, live app (Qwythos-9B first)

## Context
mojo-neuron today: lens of every neuron (9 models), CPU `fires` (3 dense models), steering through the mojo-baro
engine. Gaps: single neurons are polysemantic, everything is correlational, no MoE, no live view. the maintainer picked ideas
1-5 (transcoders, attribution graphs, cross-model map, ablation scans, MoE explorer) and all wild ideas (neuron
surgery, live brain scan, sensory output sound + image, self-explaining neurons, persona dial). Target model
**Qwythos-9B** (`~/Models/qwythos-9b-claude-mythos-5-1m-mtp-q4_k_m`, arch qwen35 hybrid linear attention): no CPU
forward exists, so every activation comes from the baro engine on the GPU. Feature dictionary = **transcoders**
(MLP-in -> sparse -> MLP-out), which also feed the attribution graphs. Three Sonnet lanes in herdr.

## D: research log, on by default (the maintainer 2026-11-09)
Every run is a research record. `src/mneuron/rlog.mojo` (owner lane B, lands first as B0, ~50 LOC) on mojo-log
(`mlog`, JSON lines): one line per event to `~/Projects/mojo/mojo-neuron/.work/rlog/<date>.jsonl` (override `NX_RLOG`,
`NX_RLOG=off` disables). Fields: ts, run id, tool + args, model path + sha256 (first 16), git sha, kind
(`normal` | `anomaly`), result summary (numbers), receipt path.
- `normal`: every finished op with its headline numbers (lens top tokens, ablation damage, FVU, steer deltas), so
  baselines accumulate.
- `anomaly`: NaN/Inf, an oracle or parity miss, a value outside the op's stated range, a prereg bar missed, a
  feature/neuron whose effect flips sign across runs, dead or always-on units, a capture that differs from the last
  run on the same input. Anomalies also go to `.work/rlog/anomalies.jsonl`.
- `nx rlog [--kind anomaly] [--since D] [--tool T]` lists them; `export_brain` turns an anomaly into a Brain note on request.
Every lane calls `rlog.event(...)` at the end of each of its ops (A, B, C items); gate: one test per lane that a run
writes a normal line and a forced NaN writes an anomaly line.

## G: neuron implants, a cheap training method? (the maintainer 2026-11-09)
Hypothesis: neurons added from a model's mistakes (closed form, no gradient) fix held-out mistakes of the same kind.
Base weights stay frozen: implants are a rank-k side FFN per layer loaded from `implants.bin`, switchable per request.
| # | Item | Owner | LOC | Gate |
|---|---|---|---:|---|
| G0 | `docs/prereg-implants.md` BEFORE any result: task families (2-digit arithmetic, country->capital, one code idiom), splits train-mistakes / held-out-mistakes / unrelated, k sweep 1/10/100/1000, random-implant control of equal size, bars for held-out gain and unrelated damage | A | doc | committed before G2 runs |
| G1 | Engine: generalise `BARO_ABLATE`'s host-side rank-1 projection to rank-k implants per layer (keys, gates, values; `implants.bin` format doc), qwen35 path (engine.mojo/window.mojo) | A | 60 | k=0 bit-equal to no implants; one implant with key=capture of prompt p changes only p's logits above a threshold; lane-merge |
| G2 | Implant builder: key = A1 capture (FFN input, normalised) on a mistake, value = unembedding direction toward the right token minus the wrong (lens), gate scale fitted so the right token wins; optional transcoder-feature keys (B1) | A | 90 | train mistakes fixed at k = train size |
| G3 | Generalisation harness: run the G0 sweep, held-out vs control, unrelated accuracy, perplexity on a fixed text; rlog every run; report with the prereg verdict | A | 80 | verdict printed against G0 bars, control included |
| G4 | Prompt -> implant compiler (context distillation): same tasks WITH vs WITHOUT a skill prompt, A1 captures, per-layer residual delta at the positions that matter, compiled to implants (and a steering-vector baseline); run WITHOUT prompt + implants. Skills: (1) JSON output format (exact match), (2) a style rule (rule linter), (3) Mojo 1.2 syntax rules (compile the output). Two verdicts, both useful (the maintainer: "even memorisation is good"): (1) generalisation (held-out vs control); (2) memorisation as cheap knowledge injection: capacity (facts held at k implants, recall on the exact prompt + 3 paraphrases), interference (unrelated accuracy, perplexity), cost (seconds per fact vs a LoRA step). G0 sets bars for both, and for G4 (score retained per skill, damage, control).
Order: after A3 (shares the surgery code). Verdict goes to the maintainer; no claim beyond the prereg.
