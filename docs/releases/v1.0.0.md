**Released:** 2026-11-09 · **Commit:** `0b209ec` · **Previous:** first release

## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
mojo-neuron reads the neurons of a GGUF language model in 11 seconds on a CPU (one layer of a 0.5B model, gate included) and steers them through the
[mojo-baro](https://github.com/amarbarosys/mojo-baro) engine 4.3 times faster than gguf-neuron-explorer. Most of the research we built on top of those
tools missed its pre-registered bar: transcoders, a lie probe, model dreams, a condition gate. The README lists the misses next to the passes.

It is a neuron explorer written in Mojo. It computes the logit lens of every neuron of a layer, shows where a neuron fires on your text (a CPU forward
for dense llama, qwen2 and granite, checked against llama.cpp), steers and ablates neurons on the GPU, captures activations for transcoders and probes,
and offers the same calls as a command line (`nx`), an MCP server and a small window app. Every tool has a gate with a planted defect.

## Highlights

- First public release: logit lens of every neuron on CPU, a CPU forward of where a neuron fires (llama, qwen2, granite, checked against llama.cpp), GPU steering and ablation through mojo-baro.
- `nx` command line, an MCP server and a window app over the same calls; every tool has a gate with a planted defect.
- Research tools: activation capture (24x faster batched prefill path), transcoder trainer, tuned lens, concept arithmetic, lie probe, neuron surgery, implants format.
- Pre-registered results published with their misses: transcoder bar, lie probe, model dreams, CAST gate, MoE router capture.

## Known limits

- GPU tools need the separately built mojo-baro engine; tested on one RX 7900 XTX (gfx1100) only.
- Transcoders do not reach the pre-registered FVU 0.55 (best 0.624 at K=256, 380k tokens); a linear ridge map reaches 0.52.
- The lie probe flips on negation; implant results (G2-G4) are still running and not in this release.
- Batched and one-position captures differ slightly (cosine >= 0.9967); do not mix them in one training set.
